# 📌 Desarrollo Full Stack

## 📖 Descripción del curso
Esta materia está enfocada en el desarrollo de aplicaciones web completas, abarcando tanto el frontend como el backend, además de la conexión con bases de datos. A lo largo del curso se aplican buenas prácticas de programación, arquitectura de software y control de versiones.

## 🎯 Objetivo general
Desarrollar aplicaciones web Full Stack utilizando tecnologías modernas, integrando interfaz de usuario, lógica del servidor y persistencia de datos.

## 🧠 Competencias a desarrollar
- Diseño y desarrollo de interfaces web responsivas  
- Implementación de lógica del lado del servidor  
- Conexión y manejo de bases de datos  
- Consumo y creación de APIs  
- Uso de control de versiones con Git y GitHub  

## 🛠️ Tecnologías utilizadas
### Frontend
- HTML5  
- CSS3  
- JavaScript  

### Backend
- Node.js  
- Express.js  

### Base de datos
- MySQL / MongoDB  

### Herramientas
- Git & GitHub  
- Visual Studio Code
